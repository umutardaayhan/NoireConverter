live_help How to Use

1. Media Processor

Drag and drop your images, audio, or video files into the primary zone. Select your target format and quality from the right panel. FFMPEG and Neural nets will accurately convert your files locally without any cloud uploads.

2. Settings & Modularity

Every tool works independently through an advanced queue system. Switch tabs freely while heavy jobs are processing.

3. Local File System & CORS

Because NOIRE is built using a modern decoupled Single Page Application (SPA), it must be served by uvicorn or identical HTTP servers. Local `file:///` executions are strictly blocked by modern Chrome features.
